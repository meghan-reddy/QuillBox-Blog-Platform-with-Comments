Project Overview

QuillBox is a full-stack blogging platform developed using Flask and SQLite that enables users to create, manage, and share blog posts while interacting through a comment system. The application provides secure user authentication, post management features, and RESTful APIs for seamless data access and integration. It is designed to demonstrate core web development concepts including authentication, database management, CRUD operations, and user interaction.

Features
User Registration and Login Authentication
Create, Read, Update, and Delete (CRUD) Blog Posts
Comment System for User Interaction
Secure Password Hashing
Session-Based Authentication
RESTful API Endpoints
SQLite Database Integration
Responsive User Interface
Ownership-Based Access Control
Cascading Delete Support for Data Integrity
Technologies Used
Python
Flask
SQLite
HTML
CSS
Jinja2 Templates
REST API
Conclusion

This project successfully implements a complete blogging platform with secure authentication, content management, and user engagement features. By combining Flask, SQLite, and REST APIs, the application provides a practical example of full-stack web development while maintaining security, scalability, and database integrity. It serves as an excellent learning project for understanding modern web application architecture and backend development.
